This R code was used on Ontario Birth Study data for the research paper: 

"Intergenerational Associations Between Mothers’ Adverse Childhood Experiences and their Children’s Cognitive and Socioemotional Outcomes" (accepted-2026)
Cloudia Rodriguez, Katherine E. Finegold, Julia A. Knight, Rayjean J. Hung, Kashtin Bertoni, Jody Wong, Stephen G. Matthews, Mark Wade

Communications Psychology, no DOI currently

Code files are ordered based on relevance and discussion in the manuscript
OBS 1-6 are analyses included in main text with the exception of post hoc EFA (supplement)
OBS 7-8 are analyses in supplemental material

Main R packages used: dplyr, MICE, lavaan, lavaan.mi
